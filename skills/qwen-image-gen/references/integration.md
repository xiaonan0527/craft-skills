# 接入已有生成环境

Skill 负责整理需求与验收；执行端负责推理。可以只使用前者，也可以接入已经授权的 API、ComfyUI 工作流或网页。

## 接入时只核对影响本次任务的参数

| 决策 | 需要核对的实际输入 |
| --- | --- |
| 文生图或编辑 | 请求里的 mode / pipeline / 对应工作流，不靠文本自动猜 |
| 参考图 | 图像节点实际收到哪些图片，编号如何映射 |
| 比例与像素 | width/height 是否被实际采样或 latent 节点使用 |
| 编辑输出 | 跟随参考图，还是指定尺寸；是否有固定面积缩放 |
| 随机性 | 种子是否固定、是否被包装层替换 |
| 透明 | 真正的 RGBA/Alpha，还是棋盘格画在 RGB 里 |
| 结果 | 原图下载入口、真实像素、任务状态与可追溯设置 |

不要推断 API 兼容性。例如 `wh_ratio` 是改写结果的语义字段，不意味着任意工作台都认识这个字段。应转换成该接口支持的尺寸参数。某条编辑工作流忽略 width/height 时，报告限制并查实际工作流，不反复放大输入尺寸。

凭据从用户已有的安全配置或环境取得，只在请求时使用；不写入提示词、报告、仓库或客户端代码。保持图像 API 与运维 API 的职责和授权分离。

异步接口提交成功后继续跟踪任务，取得原图再检查。请求结果不确定时先查原任务；支持幂等键时重用同一次逻辑请求的键，避免重复生图。

## 本项目的连接范围

仓库包含一个可选的本地 ComfyUI Qwen Image 2.1 文生图客户端，见 [comfyui-local.md](comfyui-local.md)。它不自动启动服务器、下载权重、发现任意工作流或处理凭据；生成仍要求用户环境已有模型与可访问的 ComfyUI 服务。参考图编辑和不同节点图应使用实际导出的 API 工作流适配，不能直接套用文生图节点映射。

本仓库的离线构建器是一个已实测的工作台协议示例，见 [workbench-adapter.md](workbench-adapter.md)。
